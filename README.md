# Food Store - Trabajo Integrador TypeScript

Proyecto base para evolucionar Food Store hacia una aplicación con autenticación,
sesiones persistentes y autorización por roles mediante TypeScript y
`localStorage`.

## Estructura

```text
src/
├── main.ts
├── pages/
│   ├── admin/home/
│   ├── auth/login/
│   ├── auth/registro/
│   └── client/home/
├── types/
├── utils/
└── style.css
```

La implementación de registro, login, persistencia y protección de rutas se
realizará en los siguientes pasos del trabajo práctico.
